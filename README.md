# Upskill

Учебный дневник с деревом навыков, журналом занятий, наградами и сценой с Микой.

## Локальный запуск

1. Установите Node.js и зависимости командой `npm ci`.
2. Создайте локальный `.env.local` для секретов Firebase и Gemini. Не добавляйте его в Git.
3. Запустите `npm run dev` и откройте локальный адрес Next.js.

Для production-сборки в текущей конфигурации используйте `npm run build -- --webpack`.

## Публикация

Ветка `main` подключена к Vercel и автоматически запускает deployment при каждом новом коммите. Production-сайт: https://airi-airy8.vercel.app/upskill.html
